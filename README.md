## 📖 Project Description

**Happy Pet Game** is a virtual pet simulation game developed as a Final Project for the **Object Oriented Programming** course at **Universitas Surabaya (Ubaya)**. Built entirely using **C#**, this game lets players take care of their own virtual pet — feeding it, bathing it, buying toys, and keeping it happy! 🐶🐱

---

## ✨ Key Features

- 🍖 **Feeding** — Feed your pet to keep it full and healthy
- 🛁 **Bathing** — Keep your pet clean and happy
- 🧸 **Buy Items / Toys** — Purchase toys and accessories for your pet from the in-game shop
- 😊 **Happiness System** — Your pet's mood changes based on how well you take care of it
- 🎮 **Simple & Fun Gameplay** — Easy to play, relaxing virtual pet experience

## 🚀 How to Run (Installation)

### Prerequisites

- Visual Studio (or any C# IDE)
- .NET SDK installed ([dotnet.microsoft.com](https://dotnet.microsoft.com))

### Steps

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/AudryVerly/HappyPetGame.git
   ```

2. **Navigate to the Project Directory:**
   ```bash
   cd HappyPetGame
   ```

3. **Open the project in Visual Studio** and build the solution:
   ```
   Build → Build Solution (Ctrl + Shift + B)
   ```

4. **Run the Application:**
   ```
   Debug → Start Without Debugging (Ctrl + F5)
   ```

---

## 🎮 How to Play

1. Start the game and meet your pet!
2. Keep an eye on your pet's **hunger**, **cleanliness**, and **happiness** meters.
3. **Feed** your pet when it's hungry.
4. **Bathe** your pet to keep it clean.
5. Visit the **shop** to buy toys and items to make your pet happier.
6. Keep your pet happy and healthy! 🐾
